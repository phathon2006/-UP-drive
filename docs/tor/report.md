## 1. ความเป็นมา

ความเป็นมา: ปัจจุบันนักศึกษามหาวิทยาลัยพะเยาส่วนใหญ่เดินทางระหว่างที่พัก (ในตัวเมืองพะเยาและชุมชนรอบมหาวิทยาลัย) กับมหาวิทยาลัยด้วยรถยนต์ส่วนตัวหรือรถจักรยานยนต์ โดยมักเดินทางเพียงคนเดียวในแต่ละเที่ยว ส่งผลให้สิ้นเปลืองค่าเชื้อเพลิงและค่าใช้จ่ายในการเดินทางเป็นรายวัน อีกทั้งยังเพิ่มปริมาณรถบนท้องถนนและบริเวณทางเข้ามหาวิทยาลัย แม้ว่านักศึกษาหลายคนจะมีเส้นทางและช่วงเวลาเดินทางที่ใกล้เคียงกันก็ตาม ที่ผ่านมาการรวมกลุ่มเดินทางอาศัยการสื่อสารผ่านกลุ่มแชตหรือโซเชียลมีเดีย ซึ่งไม่มีระบบจัดการข้อมูล ไม่สามารถจับคู่เส้นทางที่ใกล้เคียงกันได้อย่างมีประสิทธิภาพ ไม่มีข้อมูลยืนยันตัวตนของผู้ร่วมเดินทาง และไม่มีการติดตามสถานะหรือตำแหน่งการเดินทางที่ชัดเจน จึงเห็นควรพัฒนาแอปพลิเคชัน "UP Drive" ซึ่งเป็นระบบแชร์ค่าเดินทาง (Carpooling) บนเว็บแอปพลิเคชัน ที่ช่วยให้นักศึกษาประกาศเส้นทางความต้องการเดินทาง จับคู่ผู้ที่ไปทางเดียวกันเป็นกลุ่ม มอบหมายให้คนขับรับงาน และติดตามตำแหน่งแบบเรียลไทม์ เพื่อลดค่าใช้จ่ายในการเดินทาง ลดปริมาณรถ และเพิ่มความสะดวกและความปลอดภัยในการเดินทางร่วมกัน

## 2. ขอบเขตการดำเนินงาน (Scope of Work)

ผู้ทำงานจะต้องดำเนินการพัฒนาแอปพลิเคชันและระบบที่เกี่ยวข้อง โดยมีรายละเอียดดังนี้:

### 2.1 แพลตฟอร์มที่รองรับ

Web-application รองรับเว็บเบราว์เซอร์มาตรฐาน (Chrome, Edge, Safari, Firefox)

### 2.2 คุณลักษณะและฟังก์ชันการทำงานหลัก (Core Features)

**ระบบยืนยันตัวตนและการจัดการบัญชี (Authentication & User Profile):**

- การลงทะเบียนและเข้าสู่ระบบ (Email/Password, เบอร์โทรศัพท์ผ่าน OTP, หรือ Social Login)
- การจัดการข้อมูลส่วนตัว และการเปลี่ยนรหัสผ่าน
- ระบบกำหนดสิทธิ์การใช้งาน (Role-Based Access Control)

**ระบบการทำงานหลักของแอปพลิเคชัน (Main Modules):**

- ระบบประกาศและค้นหาคำขอเดินทาง พร้อมจับคู่ผู้โดยสารที่ไปทางเดียวกันเป็นกลุ่ม (ระบุต้นทาง–ปลายทาง พิกัดบนแผนที่ GPS และจำนวนผู้ร่วมเดินทาง)
- ระบบมอบหมายงานให้คนขับและการจัดการสถานะการเดินทาง (คนขับกดรับงาน พร้อมอัปเดตสถานะกลุ่มตลอดวงจร forming → sent_to_driver → accepted → completed / cancelled)
- ระบบติดตามตำแหน่งคนขับแบบ Realtime และประวัติการเดินทาง (แสดงตำแหน่งบนแผนที่แบบเรียลไทม์ พร้อมเส้นทางและระยะทาง)

**ระบบการแจ้งเตือน (Notifications):**

- รองรับ Push Notifications และ In-app Notifications

**ระบบจัดการหลังบ้าน (Admin Web Management):**

- ระบบดูภาพรวมและสถิติ (Dashboard & Analytics)
- ระบบจัดการข้อมูลผู้ใช้งานและเนื้อหา (Content/User Management)
- ระบบออกรายงาน (Export ข้อมูลเป็น Excel / PDF)

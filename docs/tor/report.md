## 1. ความเป็นมา

ปัจจุบันนักศึกษามหาวิทยาลัยพะเยาส่วนใหญ่เดินทางระหว่างที่พัก (ในตัวเมืองพะเยาและชุมชนรอบมหาวิทยาลัย) กับมหาวิทยาลัยด้วยรถยนต์ส่วนตัวหรือรถจักรยานยนต์ โดยมักเดินทางเพียงคนเดียวในแต่ละเที่ยว ส่งผลให้สิ้นเปลืองค่าเชื้อเพลิงและค่าใช้จ่ายในการเดินทางเป็นรายวัน อีกทั้งยังเพิ่มปริมาณรถบนท้องถนนและบริเวณทางเข้ามหาวิทยาลัย แม้ว่านักศึกษาหลายคนจะมีเส้นทางและช่วงเวลาเดินทางที่ใกล้เคียงกันก็ตาม

ที่ผ่านมาการรวมกลุ่มเดินทางอาศัยการสื่อสารผ่านกลุ่มแชตหรือโซเชียลมีเดีย ซึ่งไม่มีระบบจัดการข้อมูล ไม่สามารถจับคู่เส้นทางที่ใกล้เคียงกันได้อย่างมีประสิทธิภาพ ไม่มีข้อมูลยืนยันตัวตนของผู้ร่วมเดินทาง และไม่มีการติดตามสถานะหรือตำแหน่งการเดินทางที่ชัดเจน ทำให้การรวมกลุ่มทำได้ยากและขาดความน่าเชื่อถือ

ด้วยเหตุผลดังกล่าว จึงมีความจำเป็นต้องพัฒนาแอปพลิเคชัน "UP Drive" ซึ่งเป็นระบบแชร์ค่าเดินทาง (Carpooling) บนเว็บแอปพลิเคชัน ที่ช่วยให้นักศึกษาประกาศเส้นทางความต้องการเดินทาง จับคู่ผู้ที่ไปทางเดียวกันเป็นกลุ่ม มอบหมายให้คนขับรับงาน และติดตามตำแหน่งแบบเรียลไทม์ เพื่อลดค่าใช้จ่ายในการเดินทาง ลดปริมาณรถ และเพิ่มความสะดวกและความปลอดภัยในการเดินทางร่วมกัน

## 2. ขอบเขตการดำเนินงาน (Scope of Work)

ผู้ทำงานจะต้องดำเนินการพัฒนาแอปพลิเคชันและระบบที่เกี่ยวข้อง โดยมีรายละเอียดดังนี้:

### 2.1 แพลตฟอร์มที่รองรับ

Web-application รองรับเว็บเบราว์เซอร์มาตรฐาน (Chrome, Edge, Safari, Firefox) และออกแบบหน้าจอให้แสดงผลได้ดีบนอุปกรณ์มือถือ (Responsive) โดยทำงานร่วมกับฐานข้อมูล PostgreSQL บน Supabase และติดตั้งบนผู้ให้บริการคลาวด์ (Deploy ออนไลน์จริง)

### 2.2 คุณลักษณะและฟังก์ชันการทำงานหลัก (Core Features)

**(1) ระบบยืนยันตัวตนและการจัดการบัญชี (Authentication & User Profile)**

- การลงทะเบียนและเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน (Email/Password)
- การจัดการข้อมูลส่วนตัว (ชื่อ เบอร์โทรศัพท์ และข้อมูลยานพาหนะ) และการเปลี่ยนรหัสผ่าน
- ระบบกำหนดสิทธิ์การใช้งานตามบทบาท (Role-Based Access Control) แยกผู้ใช้ออกเป็นผู้โดยสาร (passenger) และคนขับ (driver)
- การควบคุมความปลอดภัยระดับแถว (Row Level Security) ให้ผู้ใช้เข้าถึงเฉพาะข้อมูลที่เกี่ยวข้องกับตนเอง

**(2) ระบบการทำงานหลักของแอปพลิเคชัน (Main Modules)**

- **ระบบประกาศและค้นหาคำขอเดินทาง** — ผู้โดยสารระบุต้นทาง–ปลายทาง พิกัดบนแผนที่ (GPS) และจำนวนผู้ร่วมเดินทาง
- **ระบบจับคู่กลุ่มอัตโนมัติ** — จับคู่ผู้โดยสารที่ไปทางเดียวกันเป็นกลุ่ม โดยคำนวณระยะทางและจัดอันดับกลุ่มที่ใกล้ที่สุด
- **ระบบมอบหมายงานให้คนขับ** — คนขับดูกลุ่มที่รอรับงานและกดรับงาน พร้อมอัปเดตสถานะกลุ่มตลอดวงจร (forming → sent_to_driver → accepted → completed / cancelled)
- **ระบบติดตามตำแหน่งแบบ Realtime** — แสดงตำแหน่งคนขับบนแผนที่แบบเรียลไทม์ พร้อมเส้นทางและระยะทางของกลุ่ม
- **ระบบประวัติการเดินทาง** — แสดงรายการและสถานะการเดินทางที่ผ่านมาของผู้ใช้

**(3) ระบบการแจ้งเตือน (Notifications)**

- การแจ้งเตือนในแอป (In-app Notifications) เมื่อกลุ่มถูกจับคู่ มีคนขับรับงาน หรือสถานะการเดินทางเปลี่ยน โดยอัปเดตแบบเรียลไทม์ผ่าน Supabase Realtime
- การแจ้งเตือนบนอุปกรณ์ (Push Notifications) สำหรับเหตุการณ์สำคัญ เช่น เมื่อคนขับรับงานหรือใกล้ถึงจุดรับ

**(4) ระบบจัดการหลังบ้าน (Admin Web Management)**

- ระบบดูภาพรวมและสถิติ (Dashboard & Analytics) — จำนวนกลุ่ม/เที่ยวการเดินทาง อัตราการจับคู่สำเร็จ และสถิติการใช้งาน
- ระบบจัดการข้อมูลผู้ใช้งานและเนื้อหา (Content / User Management)
- ระบบออกรายงาน (Export ข้อมูลเป็น Excel / PDF)

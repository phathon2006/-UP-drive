4. ผลการทดสอบ — การตั้งเวลาอัตโนมัติ

ทดสอบโดยเปลี่ยนสถานะกลุ่มไปเรื่อย ๆ แล้วดูว่าเวลาในคอลัมน์ confirmed_at, accepted_at, completed_at ถูกเติมเองโดย Trigger หรือไม่

1สร้างกลุ่มใหม่ (status = forming)
insert into public.ride_groups (id, leader_id, target_passengers, status)
